# Desarrollo-de-una-aplicación-web-Pomodoro-en-una-VPS.

# Proyecto ASIR – Aplicación Web Pomodoro

## 1. Descripción del proyecto

Este proyecto consiste en desarrollar una aplicación web basada en la técnica Pomodoro, cuyo objetivo es ayudar a los usuarios a organizar su tiempo de estudio y trabajo mediante intervalos de concentración y descanso.

La aplicación estará alojada en un VPS real y será accesible desde Internet, permitiendo que los usuarios puedan registrarse, iniciar sesión y utilizar el temporizador desde cualquier dispositivo con conexión a Internet.

## 2. Objetivos del proyecto

- Desarrollar una aplicación web funcional y accesible desde Internet.
- Implementar un sistema de registro e inicio de sesión de usuarios.
- Crear un temporizador basado en la técnica Pomodoro.
- Permitir alternar entre periodos de trabajo y descanso.
- Almacenar los usuarios y sus sesiones de trabajo en una base de datos.
- Configurar y administrar un servidor Linux alojado en un VPS.
- Aplicar medidas de seguridad para proteger el servidor y la información de los usuarios.

## 3. Funcionalidades principales

- **Registro de usuarios:** permitirá crear una cuenta personal.
- **Inicio de sesión:** permitirá acceder a la aplicación mediante credenciales.
- **Temporizador Pomodoro:** permitirá controlar los intervalos de trabajo y descanso.
- **Gestión de sesiones:** registrará el tiempo dedicado al trabajo.
- **Base de datos:** almacenará la información de los usuarios y sus sesiones.

## 4. Tecnologías previstas

| Tecnología | Uso |
|---|---|
| Ubuntu Server | Sistema operativo del servidor |
| VPS | Alojamiento de la aplicación |
| Python y Flask | Desarrollo de la aplicación web |
| HTML | Estructura de las páginas |
| CSS | Diseño de la interfaz |
| JavaScript | Funcionamiento del temporizador |
| MySQL | Gestión de la base de datos |
| Git y GitHub | Control de versiones y almacenamiento del código |

## 5. Módulos de ASIR relacionados

- **ASO (Administración de Sistemas Operativos):** instalación, configuración y administración de Ubuntu Server.
- **ASGBD (Administración de Sistemas Gestores de Bases de Datos):** instalación y configuración de MySQL, creación de tablas y gestión de usuarios.
- **IAW (Implantación de Aplicaciones Web):** desarrollo, configuración y despliegue de la aplicación web.
- **PAR (Planificación y Administración de Redes):** configuración de la conectividad y acceso al servidor desde Internet.
- **Seguridad y Alta Disponibilidad:** aplicación de medidas de protección, gestión de permisos y copias de seguridad.

## 6. Seguridad

Se tendrán en cuenta diferentes medidas de seguridad:

- Protección de las contraseñas mediante funciones de hash seguras y salt.
- Configuración de permisos y usuarios del sistema.
- Actualización del sistema operativo y sus paquetes.
- Configuración del cortafuegos.
- Protección del acceso remoto al servidor.
- Realización de copias de seguridad de la base de datos.

## 7. Resultado esperado

Al finalizar el proyecto se espera disponer de una aplicación web Pomodoro completamente funcional, alojada en un VPS real y accesible desde Internet.

Los usuarios podrán registrarse, iniciar sesión, utilizar el temporizador y consultar el registro de sus sesiones de trabajo.

Además, se habrá realizado la instalación, configuración, administración y protección de un servidor Linux en un entorno real.
