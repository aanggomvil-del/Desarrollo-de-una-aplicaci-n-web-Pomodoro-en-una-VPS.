01 / EL PROYECTO

¿En qué consiste?

Este proyecto consiste en desarrollar una aplicación web de gestión del tiempo mediante la técnica Pomodoro. Su finalidad es ayudar a los usuarios a organizar sus tareas mediante intervalos de trabajo y descanso.

🎯 Objetivo

Facilitar la organización del tiempo y mejorar la concentración durante las actividades diarias.

💡 Necesidad

Ofrecer una herramienta sencilla para gestionar sesiones de trabajo, controlar descansos y consultar el tiempo dedicado a cada sesión.

02 / FUNCIONALIDADES

¿Qué permitirá hacer?

👤

Registro e inicio de sesión

Crear una cuenta e iniciar sesión de forma segura.

⏱️

Temporizador Pomodoro

Controlar los intervalos de trabajo y descanso.

📊

Historial de sesiones

Guardar y consultar las sesiones y el tiempo trabajado.

🔒

Gestión de usuarios

Almacenar los datos y las sesiones de cada usuario.

JavaScript Interactividad

Nginx Servidor web y proxy inverso
