Aplicación Web Pomodoro

Proyecto de fin de ciclo - ASIR

Descripción del proyecto

El proyecto consiste en desarrollar una aplicación web basada en la técnica Pomodoro para ayudar a los usuarios a organizar su tiempo, mejorar su concentración y alternar periodos de trabajo y descanso.

Necesidad o problema que resuelve

La aplicación pretende facilitar la gestión del tiempo y ayudar a las personas que tienen dificultades para organizar sus tareas, mantener la concentración y controlar sus periodos de descanso.

Objetivos principales

  • Desarrollar una aplicación web funcional de gestión del tiempo.
  • Permitir el registro y acceso de usuarios.
  • Implementar un temporizador basado en la técnica Pomodoro.
  • Almacenar las sesiones de trabajo de cada usuario.
  • Desplegar la aplicación en un servidor VPS real accesible desde Internet.

Funcionalidades previstas

  • Registro e inicio de sesión de usuarios.
  • Temporizador para sesiones de trabajo y descanso.
  • Registro de las sesiones realizadas.
  • Almacenamiento de los datos de los usuarios.
  • Consulta del historial de sesiones.

Tecnologías que se utilizarán

  • Ubuntu Server: sistema operativo del servidor VPS.
  • VPS: alojamiento de la aplicación en Internet.
  • HTML, CSS y JavaScript: desarrollo de la interfaz web.
